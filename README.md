# smart-inventory-supply-chain-sql-streamlit
A production-ready data warehouse and analytics solution built entirely on SQL to optimize supply chain logistics, predict inventory stockouts, and streamline warehouse fulfillment tracking. This project implements advanced relational database modeling, transactional logging, and analytical window functions to turn raw inventory data into actionable business intelligence.
🎯 Core Functionality & Use CasesDemand Forecasting & Reorder Points: Uses moving averages and historical sales velocities to dynamically calculate when and how much stock to reorder.Supplier Performance Tracking: Measures supplier reliability by auditing discrepancies between scheduled delivery times and actual receipt timestamps.Warehouse & Shelf-Life Optimization: Tracks stock batches (FIFO/LIFO) to monitor storage aging, reduce item spoilage, and balance inventory levels across multiple warehouse locations.Automated Stockout Mitigation: Employs event-driven logic to instantly identify low-stock exceptions before they disrupt active fulfillment channels.
